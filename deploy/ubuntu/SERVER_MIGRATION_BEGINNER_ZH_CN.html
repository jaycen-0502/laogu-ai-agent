老谷系统更换服务器

小白一键迁移教程 · 适用于继续使用 api.jaycwl.org 的情况

快速导航：准备旧服务器备份新服务器恢复切换域名验收回退

先看结论

迁移后会保留用户、工作区、Agent、Token、设备绑定、授权、任务和脚本。若域名不变，浏览器、控制中心和 Agent 通常不需要重新打包或注册。

不会自动迁移：Windows 本地浏览器 Profile、Cookie、登录状态和代理配置。这些数据仍在原电脑上。

一、准备工作

  • 新服务器建议 Ubuntu 24.04 LTS，至少 2 核、4 GB 内存、80 GB 磁盘。
  • 安全组开放 TCP 22、80、443，不要开放 PostgreSQL 5432。
  • 准备新服务器 IP、证书邮箱，以及旧服务器 SSH 登录权限。
  • 提前将 Cloudflare DNS TTL 调低；正式切换时只保留一台服务器写入。
以下密钥和备份包含敏感信息，不能上传 GitHub、网盘或发送给他人。

二、在旧服务器生成备份

登录旧服务器后执行：

cd /opt/laogu-ai-agent
sudo systemctl stop laogu-server
sudo bash deploy/ubuntu/create-server-migration-bundle.sh
sudo ls -lh /var/backups/laogu/server-migration-*
sudo ls -lh /var/backups/laogu-auto/

安全保存最新的加密恢复包及校验文件，并单独保存：

  • laogu-backup-recovery.key
  • /etc/laogu/license/Laogu-License-Issuer.pem
  • /etc/laogu/license/Laogu-License-Password.txt

三、把材料放到新服务器

新服务器准备全新的系统，然后上传恢复包、校验文件、恢复私钥和授权签发文件：

sudo install -d -m 700 /root/restore
chmod 600 /root/restore/*

可使用 Windows PowerShell 的 scp 上传。不要把真实密钥粘贴到网页或聊天中。

四、在新服务器恢复

apt update
apt install -y git ca-certificates
git clone https://github.com/jaycen-0502/laogu-ai-agent.git /opt/laogu-ai-agent
cd /opt/laogu-ai-agent
git checkout codex/multi-engine-v0.21.9

执行恢复向导（把文件名和邮箱替换成实际值）：

sudo bash /opt/laogu-ai-agent/deploy/ubuntu/restore.sh \
  --domain api.jaycwl.org \
  --email 你的证书邮箱 \
  --package /root/restore/laogu-recovery-时间.tar.gz.age \
  --checksum /root/restore/laogu-recovery-时间.tar.gz.age.sha256 \
  --key /root/restore/laogu-backup-recovery.key

出现确认提示时输入大写：RESTORE。等待脚本完成，不要重复运行。

五、切换域名

恢复完成后，在 Cloudflare 将 api.jaycwl.org 的 A 记录改为新服务器 IP。建议先使用“仅 DNS（灰色云）”，确认 HTTPS 正常后再打开代理。

如果域名不变，客户端配置无需修改；如果域名改变，则要修改控制中心的 config\laogu.env 和浏览器的 config.yaml。

六、迁移后验收

sudo systemctl is-active laogu-server nginx postgresql
curl -fsS https://api.jaycwl.org/api/health/ready
sudo bash /opt/laogu-ai-agent/deploy/ubuntu/verify.sh api.jaycwl.org
sudo -u postgres psql -d laogu -At -c "SELECT version_num FROM alembic_version;"
  • 管理员可以登录后台
  • 用户、工作区、Agent、授权和任务仍存在
  • 控制中心可以连接服务器，Agent 心跳正常
  • 浏览器授权检查、续期和设备绑定正常
  • 脚本列表、日志和任务状态正常

重新开启 Telegram 自动备份

cd /opt/laogu-ai-agent
sudo bash deploy/ubuntu/install-backup.sh
sudo systemctl start laogu-backup.service
sudo journalctl -u laogu-backup.service -n 100 --no-pager

七、失败时回退

如果新服务器验收失败，先停止新服务器，再把 Cloudflare DNS 改回旧 IP：

sudo systemctl stop laogu-server

回到旧服务器启动服务：

sudo systemctl start laogu-server
sudo systemctl is-active laogu-server
新旧服务器不要同时长期运行并接收写入，否则数据不会自动合并。

八、迁移完成后的清理

如果旧服务器存在 /etc/laogu/license/ 下的授权签发私钥和密码文件，新版自动备份会将它们放入 age 加密包，恢复脚本也会自动还原；旧版备份可能没有这两项，需要单独安全复制。

确认新服务器稳定运行 3-7 天、自动备份成功后，再删除新服务器 /root/restore/ 中的临时密钥和备份文件。旧服务器建议暂时保留，确认无误后再下线。
